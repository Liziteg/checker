# Новые сцены с котом-маскотом

Добавьте статичные изображения кота и описание сцен в этот каталог. 

1. Сохраните иллюстрации в формате SVG или PNG. Рекомендуемое имя файла — `scene-name.svg`.
2. Зарегистрируйте новую сцену в файле `cat-scenes.json`, указав путь к изображению, подпись и позицию размещения.
3. Для каждой сцены задайте уникальный `id`, чтобы механизм ротации не повторял одну и ту же сцену подряд.

Пример объекта сцены:
```json
{
  "id": "desk-analyst",
  "ariaLabel": "Чёрный кот внимательно изучает монитор.",
  "image": "assets/cat_scenes/desk-analyst.svg",
  "message": "Следим за метриками и не пропускаем ни одной аномалии.",
  "positionClass": "cat-mascot--top-right"
}
```

> Поддерживаемые классы позиционирования описаны в `style.css`.
